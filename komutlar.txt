projeyi çalıştırma komutu:
php artisan serve

projeye controller ekleme komutu (BlogController örnek controller adıdır)
php artisan make:controller BlogController

Blog yazısı modeli ve migration dosyası oluşturma komutu:
php artisan make:model Post -m

Migration dosyalarını veritabanında çalıştırma komutu:
php artisan migrate

Migration dosyalarını tekrar aktarmak için 
php artisan migrate:fresh

Blog için örnek Türkçe yazıları veritabanına ekleme komutu:
php artisan migrate:fresh --seed

100 örnek kullanıcıyı rollerle oluşturma komutu:
php artisan db:seed --class=UserSeeder
Örnek yönetici e-postası: admin@example.test
Örnek kullanıcıların başlangıç şifresi: password (yalnızca geliştirme ortamı için)

Değişiklikleri script ile GitHub'a gönderme komutu (Windows):
py commit_push.py
Script commit mesajını sorar; boş bırakırsanız tarih ve saat içeren varsayılan mesajı kullanır.

Değişiklikleri elle GitHub'a gönderme komutları:
git add -A
git commit -m "Değişiklik açıklaması"
git push origin main

Yeni bir projeyi GitHub'da repo olarak açıp ilk kez göndermek:
1. GitHub'da New repository seç. Repo adını yaz ve boş repo oluştur (README, .gitignore ve lisans ekleme).
2. Terminalde yeni proje klasörüne gir ve aşağıdaki komutları sırayla çalıştır:
git init
git add -A
git commit -m "İlk commit"
git branch -M main
git remote add origin https://github.com/KULLANICI_ADI/REPO_ADI.git
git push -u origin main
KULLANICI_ADI ve REPO_ADI bölümlerini kendi GitHub kullanıcı adın ve repo adınla değiştir.
